# AD-Tools – öffentliche Daten

Öffentlich lesbare Referenzwerte für die [AD-Tools](https://github.com/tslabs-web/ad-tools), z. B. Baupreisindex und gleitender Neuwertfaktor für den Gebäudewert-Rechner.

- `faktoren.json` – aktuelle Faktoren mit Stand-Datum und Quellen

**Hier gehören niemals Kunden- oder personenbezogene Daten hinein** – das Repo ist öffentlich.
Die App lädt nur diese Datei; ohne Internet nutzt sie die eingebauten Werte.
